# Nota Content Sources — KSSM 2026

This file records the curriculum sources used to define the Phase 3 content
snapshot. It is an audit trail for developers, not an in-app bibliography.

## Primary curriculum structure

### Jabatan Muzium Malaysia — IPIM

Dokumen Kurikulum lists KSSM DSKP and Perincian DSKP for Tingkatan 1, 2, 3,
4 and 5.

https://ipim.jmm.gov.my/pengenalan-1p1m/senarai-rph-ppm/dokumen-kurikulum

The Perincian DSKP documents map DSKP learning standards to the corresponding
textbook chapters and subtopics. Those mappings are the primary structure used
for the 46 native chapter assets.

Example Tingkatan 5 mapping:

https://ipim.jmm.gov.my/sites/default/files/dockokurikulum/T5_DSKP%20VS%20BUKU%20TEKS%20_ZAR.pdf

The combined official KSSM Sejarah Tingkatan 4 dan 5 DSKP is also linked by
IPIM and used for cross-checking learning standards.

## Curriculum transition

Kementerian Pendidikan Malaysia states that Kurikulum Persekolahan 2027 starts
for the new Year 1 and Tingkatan 1 cohorts in 2027.

https://www.moe.gov.my/kurikulum-persekolahan-2027

KPM's 11 February 2026 media statement also confirms that the new curriculum
starts in 2027 for Year 1 and Tingkatan 1, and that secondary History is
offered from Tingkatan 1.

For that reason, this repository labels the current content explicitly as
`KSSM / 2026.1`. Future KP2027 Tingkatan 1 content must use a separate
curriculum/version namespace.

## Editorial rule

Native notes are original revision summaries. They should:

1. preserve the official chapter/subtopic structure;
2. state dates, institutions and historical events accurately;
3. distinguish description from interpretation where appropriate;
4. avoid copying long textbook passages;
5. remain concise enough for revision;
6. be re-reviewed whenever KPM changes the applicable curriculum.

Review date for version `2026.1`: **25 September 2026**.
