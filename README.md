# Notaku Sejarah V2

A modern, responsive Flutter rebuild of **Notaku Sejarah**.

This repository is currently in **Phase 1 — Foundation & CI/CD**.

## Phase 1 goals

- Establish a clean Flutter project foundation.
- Prepare responsive architecture for phone and tablet layouts.
- Add automated analysis and tests with GitHub Actions.
- Build Android APK artifacts in GitHub Actions.
- Prepare a Flutter Web preview for GitHub Pages.

## Project status

Foundation in progress.
